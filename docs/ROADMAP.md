# Implementation phases and next steps

## Phase 1 — implemented MVP

- Installable self-contained Codex skill and strict JSON specification.
- Agent-directed source understanding with per-object evidence quotations.
- Three executable original method fixtures: VLM, tool/memory agent, physical VLN.
- Shared-scene SVG, editable native PPTX, vector PDF, PNG/preview and Draw.io source.
- Caption-free/footer-free defaults and global/per-module typography controls.
- Layout/structural checks, mutation tests, native connector path checks,
  deterministic SVG/PPTX regeneration and optional independent Office rendering.

## Phase 2 — partial implementation, next improvements

Implemented: one actual built-in image-generation reference, prompt preparation,
agent-directed editable reconstruction, paper/monochrome palette candidates,
render diagnostics and bounded feedback guidance. User visual feedback drove
removal of title/footer defaults, token decoration and ambiguous shared routes.

Next: add several genuinely different composition candidates per frozen semantic
graph; improve glyphs only when they convey supported meaning; font-metric shaping
for user-selected fonts; explicit panel/detail-inset support; obstacle-aware label
placement; robust dense-loop routing; automatic endpoint attachment that survives independent
Office rendering without changing the visual route. A visual model can propose edits, but each
iteration must preserve the semantic graph and retain before/after evidence.
No learned aesthetic optimizer or unattended vision-feedback loop is claimed.

## Phase 3 — designed, not yet a populated paper corpus

The packaged library policy and empty machine-readable index define provenance and
rights requirements. Next, select a small user-approved paper set, inspect its
method and figures, record original pattern summaries and rights, and create a
link-only index. Add downloadable assets only with documented permission.
Measure paper coverage, missing sources and labeling disagreement. Avoid copying
paper figures into templates or assuming that all arXiv assets are reusable.

## Research evaluation needed

Run a blind human evaluation on real, independently supplied methods. Compare
semantic errors/omissions, visual clarity at paper size, successful edit tasks and
editing time. Include every assigned case and retain failures. A three-example
software test suite is not evidence that the skill reaches top-conference quality.

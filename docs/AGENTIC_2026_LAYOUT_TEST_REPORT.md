# Measured layout and editable-arrow workflow: 2026 paper tests

Date: 2026-11-16. Final artifacts: `paperfigure/examples/agentic-2026-layout/{agemem,memskill}/output-v12/`.
The skill now routes text alignment, overflow, routing and connector-editability
requests through `paperfigure/references/layout-and-arrows.md`. This is an actual
native SVG/PPTX implementation and two paper-backed tests, not prompt-only advice.

## Scope and source authority

- AgeMem, arXiv **2601.01885v1**, 2026-01-05: Figure 1(c), page 2, selected unified-management panel only.
- MemSkill, arXiv **2602.02474v1**, 2026-02-02: entire Figure 2, page 4.
- Frozen PDF and HTML snapshots, original authorship/license links, crop coordinates,
  scaling and SHA-256 evidence are in each `source/provenance.json`. Both sources
  declare CC BY 4.0. The original authors retain copyright.
- External LaTeX captions, comparison panels outside the selected input, and new
  titles/footnotes were not added. Original in-figure labels remain intact.
- User-requested solid fills supersede the source gradient styling. Source colors
  and semantic roles are otherwise retained; test-only arrow styles live separately.

## Implemented contract and checks

The typed layout scene records semantic owners/hierarchy, native text primitives,
logical edges/edge operations, boxes, padded label regions, explicit anchors,
polyline routes, head/tail size/type, width, color, dash/gap and cap. Separate
semantic and topology hashes guard reflow. Text is measured with actual Chromium
glyph ink and character transforms; positioned advance additionally guards native
paragraph wrapping. The router uses obstacle-aware orthogonal visibility search
and fails explicitly when no feasible corridor exists.

Checks cover padded overflow, multiline-block centering, text overlap, source
module stacks, route/text/module interference, conservative arrowhead envelopes,
detached/missing endpoints, actual SVG route parity, opaque label overpainting,
visibility and raster substitution. Exact source text/shape occlusion exceptions
require both source-PNG SHA-256 and relative-geometry fingerprint. Typography or
relative position edits invalidate them; joint translation preserves them.

Native PPTX exports editable text blocks/shapes and actual `p:cxnSp` connectors.
Transparent native attachment helpers belong to the owning module group and are
explicitly excluded from content counts. The audit reads the actual ZIP/XML,
checks native styles/bindings/label coverage and computes the ratio from actual
slide objects. Full PPTX and isolated text/connector decks are independently
rendered through LibreOffice/PDF/MuPDF, checking real ink, line counts and route
coverage. XML success is not used as a substitute for these rendered checks.

## Actual editing tests

Both final scenes were copied to separate `edit-test-v2/` outputs:

- AgeMem: move `query` by +12 px horizontally; reroute `query-input`.
- MemSkill: move `task-reward` by +12 px vertically; reroute incident edges.
- In each case, change one arrow's color, width, explicit dash/gap, head type,
  head size and cap. Test colors are not included in the delivered figure.
- Both tests pass measured SVG QA, native XML audit and independent PPTX rendering,
  including isolated centered text and connectors. Semantic and topology hashes
  remain unchanged. Records: `layout-changes.json`, `native-audit.json`,
  `native-render/render-qa.json`, and final `verification-final.json`.

This verifies scene-based editing and native property representation. It does not
claim interactive Microsoft PowerPoint dragging was tested, or that every segment
of a complex polyline automatically reroutes after an arbitrary GUI drag.

## Regression and isolated review

- Default `npm test`: **81 / 81 pass, 0 skipped**, about 9 seconds. Includes real
  Chromium layout tests; `test:unit` alone is intentionally narrower.
- Negative tests catch measured overflow/centering, detached and missing edges,
  route mismatch/blocked corridors, thick heads touching text, invisible labels,
  opaque overpainting, missing exception evidence, relative/font edits invalidating
  exceptions, native head/dash/binding corruption and raster-object substitution.
- `git diff --check` passes. Source reconstruction and generation commands and
  environment requirements are documented in the example README.
- Independent code acceptance: `LAYOUT_WORKFLOW_INDEPENDENT_REVIEW_FINAL.md`.
- Independent source acceptance: `AGENTIC_2026_SOURCE_AUDIT_V11.md`. Final v12 has
  identical topology and semantic hashes; only layout/style refinements followed.
- Independent final visual acceptance: **PASS for both cases**,
  `AGENTIC_2026_ISOLATED_VISUAL_REVIEW_V12.md`. Reviewer inspected original PNG,
  SVG preview and actual independently rendered PPTX, with exact artifact hashes.
- `examples/agentic-2026-layout/delivery.json` binds output hashes, test evidence
  and separate mechanical/source/visual/code acceptance dimensions.

Earlier failures remain as immutable evidence: incorrect font fallback, three-line
native wrapping of a two-line source label, native custom-site interpretation,
missing zero-area source line, formula/head collision, and a side-lane endpoint
slightly inside a visible box. The first isolated v11 visual review requested
changes; v12 repaired them. Mechanical route coverage alone missed the last
boundary defect, demonstrating why isolated visual review remains mandatory.

## Remaining differences and unsupported claims

- Installed source-matched fonts and editable math are approximate recovery, not
  exact original embedded font recovery. Source informal typography was retained.
- Small raster icons are ten-color vector-contour approximations with some fine
  detail loss. No words are traced, and no full PNG is embedded.
- Gradient/shadow ornament was flattened intentionally. AgeMem input-arrow weight
  was restored as broad native solid arrows. MemSkill ambiguous reward routing was
  resolved from the paper to Controller, never to the frozen Executor.
- Native bound curve export is not implemented; tested native routes are polylines.
- Render engine: isolated Chromium for SVG measurement; LibreOffice -> PDF ->
  MuPDF for independent PPTX checks. No interactive Microsoft PowerPoint test.
- These are two frozen paper cases, not a broad benchmark or a universal PNG
  converter. PNG-only reconstruction remains agent-assisted. Mechanical and visual
  passes do not establish NeurIPS/ICML publication-quality acceptance.
